title: Threat intelligence and how vulnerabilities are scored
domain: Domain 2: Threats, Vulnerabilities, and Attacks
obj: 2.1
level: Intermediate
min: 120
pre: w4-4, w5-1
out: Use intelligence sources and threat feeds appropriately.
out: Read a CVE entry and a CVSS score.
out: Prioritize vulnerabilities using more than a score alone.
why: No organization can fix everything at once. Threat intelligence and scoring help teams spend limited time on what is most likely to hurt them.
plain: Weather forecasts help you decide whether to carry an umbrella. Threat intelligence is a forecast for attacks. A CVE number is like a catalogue number for one specific known flaw, and a CVSS score is a severity rating for that flaw.
tech: A threat has a likelihood, how probable it is, and an impact, how harmful it would be. The threat life cycle describes how a threat emerges, becomes active and declines, and intelligence itself follows a cycle of direction, collection, analysis, dissemination and feedback.
tech: Intelligence sources include open-source intelligence (OSINT), commercial providers, government advisories, industry groups such as Information Sharing and Analysis Centers (ISACs), and internal logs. Threat feeds deliver indicators such as malicious IP addresses and file hashes, often in machine-readable formats. Feeds lose value quickly, so age and context matter.
tech: Common Vulnerabilities and Exposures (CVE) assigns a unique ID to a publicly known vulnerability, such as CVE-2021-44228. The Common Vulnerability Scoring System (CVSS) scores severity from 0.0 to 10.0. CVSS measures severity and does not alone measure your risk. Vulnerability types describe the kind of weakness, such as those in the Common Weakness Enumeration (CWE), for example injection or buffer overflow.
tech: Prioritization combines severity with context: is the system exposed to the internet, is the flaw being actively exploited, how important is the asset, and what controls already exist? CISA's Known Exploited Vulnerabilities catalog lists flaws seen in real attacks, which is strong evidence for acting quickly.
table: CVSS severity bands | Score | Rating
| 0.0 | None
| 0.1 to 3.9 | Low
| 4.0 to 6.9 | Medium
| 7.0 to 8.9 | High
| 9.0 to 10.0 | Critical
term: Threat feeds == Regularly updated streams of threat indicators.
term: Intelligence sources == Places threat information comes from, such as OSINT or government advisories.
term: OSINT == Open-source intelligence: information gathered from public sources.
term: Likelihood == How probable an event is.
term: Impact == How much harm an event would cause.
term: Life cycle == The stages a threat, or threat intelligence, moves through.
term: CVE == Common Vulnerabilities and Exposures: unique IDs for known flaws.
term: CVSS == Common Vulnerability Scoring System: a 0 to 10 severity scale.
term: Scoring == Assigning a value that expresses severity or priority.
term: Prioritization == Deciding what to fix first using severity and context.
term: Vulnerability types == Categories of weakness, such as injection.
term: CWE == Common Weakness Enumeration: a catalogue of weakness types.
term: NVD == National Vulnerability Database: NIST's database of CVE records and scores.
eg: A CVSS 9.8 flaw on an isolated test server can be less urgent than a CVSS 7.5 flaw being actively exploited on an internet-facing payment system.
eg: A feed flags an IP address as malicious, but that address is shared cloud infrastructure, and blocking it would stop legitimate business. Context prevents an outage.

@lesson w6-3
title: Threat vectors part 1: messages, files, browsers, networks and remote access
domain: Domain 2: Threats, Vulnerabilities, and Attacks
obj: 2.3
level: Intermediate

pre: w6-2, w3-3
out: Identify message, image, attachment and browser-based vectors.
out: Explain network-based and remote access vectors.
out: Describe an advanced persistent threat.
why: A vector is the route an attacker uses to get in. If you can name the route, you can choose a control for it.
plain: A threat vector is the way in: the unlocked door, the delivery driver, the open window. An advanced persistent threat is a burglar who moves in quietly and lives in your attic for months.
tech: An advanced persistent threat (APT) is a skilled, well-funded attacker that keeps long-term, stealthy access to a target. Message-based vectors include email, Short Message Service (SMS), Rich Communication Services (RCS), instant messaging and collaboration tools such as shared chat platforms. All can deliver links or impersonation.
tech: Image-based vectors include quick response (QR) codes that hide a malicious link, embedded content such as images with tracking or hidden data, and tricks involving CAPTCHA. A CAPTCHA, or Completely Automated Public Turing test to tell Computers and Humans Apart, can be imitated on fake pages, which then instruct people to paste and run commands.
tech: Attachment-based vectors include embedded macros in office documents, Rich Text Format (RTF) documents and Portable Document Format (PDF) files that exploit a reader or contain malicious links. Browser-based vectors include malicious extensions; JavaScript running in a page; weaknesses involving password managers, such as fake autofill forms; stolen cookies; and theft of session tokens, which can let an attacker act as a signed-in user without knowing the password.
tech: Network-based vectors include attacks on infrastructure devices such as routers and firewalls, attacks on virtualized devices and hypervisors, and capture of session keys. Remote access vectors include remote desktop services exposed to the internet, Virtual Network Computing (VNC) and virtual private network (VPN) gateways, which are frequent targets of credential attacks and unpatched flaws.
term: Threat vector == The path an attacker uses to reach a target.
term: APT == Advanced persistent threat: a skilled attacker with long-term access.
term: SMS == Short Message Service: ordinary text messaging.
term: RCS == Rich Communication Services: the modern messaging upgrade to SMS.
term: Instant messaging == Real-time chat applications.
term: Collaboration tools == Shared workspaces, chat and document platforms.
term: QR code == A quick response code: a scannable image that can hide a link.
term: Embedded content == Images or objects included in another document or message.
term: CAPTCHA == A test meant to separate people from bots, which attackers can imitate.
term: Embedded macros == Scripts stored inside office documents.
term: RTF == Rich Text Format: a document format that has been used to deliver exploits.
term: PDF == Portable Document Format: a file type that can carry links and exploits.
term: Extensions == Add-ons that run inside a browser.
term: JavaScript == Code that runs in the browser on a web page.
term: Password managers == Tools that store credentials, which attackers may try to trick or attack.
term: Cookies == Small pieces of data a browser stores and sends to websites.
term: Session tokens == Values that show a user has already signed in.
term: Infrastructure devices == Routers, switches and firewalls.
term: Virtualized devices == Software-based network and server appliances.
term: Session keys == Temporary keys that protect one connection.
term: Remote desktop == A way to control a computer's graphical desktop over a network.
term: VNC == Virtual Network Computing: a remote desktop system.
term: VPN == A virtual private network, whose gateways are common targets.
eg: A QR code sticker placed over a real one on a parking meter sends drivers to a fake payment page.
eg: Attackers steal a session cookie from an infected laptop and replay it, bypassing the password and MFA already completed by the user.

- Note that real attacks often combine several vectors.

title: Threat vectors part 2: endpoints, supply chain, people, IoT, OT, physical and signals
domain: Domain 2: Threats, Vulnerabilities, and Attacks
obj: 2.3

out: Explain endpoint and living-off-the-land techniques.
out: Identify supply chain, human, external media, IoT, OT and physical vectors.
out: Describe signal-based vectors such as Bluetooth and NFC.
why: Attackers often go around strong perimeter defenses, through a supplier, a USB drive or a smart camera. These indirect routes are often less well watched.
plain: If the front door is strong, a burglar might arrive with the cleaning company, leave a free USB stick in the parking lot or use your own ladder from the garden shed. Those are the routes this lesson covers.
tech: Endpoint-based vectors involve mobile devices, workstations, servers and tablets. Trusted devices can be abused because other systems accept them. Attackers also misuse built-in tools already on a system, called living-off-the-land tools, such as PowerShell or certutil, because activity using legitimate administration software is harder to spot.
tech: Supply chain-based vectors exploit trust in third-party providers. These include managed service providers with remote access to many customers, logistic providers who handle physical goods, and software as a service (SaaS) providers holding customer data. A malicious software update is the classic example. External media-based vectors include a malicious Universal Serial Bus (USB) device, which may act as a keyboard or carry malware.
tech: Human-based vectors include impersonation of a trusted person; a contractor or a visitor given more access than needed; a biometric weakness, such as spoofing a fingerprint or face; and a watering hole attack, which compromises a website the target group visits regularly.
tech: Internet of Things (IoT) based vectors include cameras, sensors and printers, which often have weak defaults and rarely receive updates. Operational technology (OT) based vectors affect industrial control systems, where a compromise can have physical consequences and patching is difficult. Physical-based vectors include defeating lock and key systems, bypassing an access vestibule and stealing or cloning access passes. An access vestibule, often called a mantrap, is a small space with two doors that do not open at once.
tech: Signal-based vectors use wireless channels. Bluetooth can be abused to pair without consent or to send unsolicited messages. Radio frequency (RF) attacks include jamming and interception. Near-field communications (NFC) operate at very short range, for tap-to-pay and access cards, and can be subject to relay and cloning.
term: Mobile devices == Phones and similar portable computers.
term: Workstations == Desktop or laptop computers used by staff.
term: Servers == Computers that provide services to others.
term: Tablets == Portable touchscreen computers.
term: Trusted devices == Devices other systems accept with less checking.
term: Built-in tools == Administration software already included with the operating system.
term: Living-off-the-land tools == Legitimate tools abused to avoid detection.
term: Third-party providers == External companies that deliver services or goods.
term: Managed service providers == Companies that run IT for customers, often with broad access.
term: Logistic providers == Companies that move physical goods.
term: SaaS providers == Software as a service companies holding customer data.
term: Malicious USB == A USB device designed to attack the computer it is plugged into.
term: Impersonation == Pretending to be someone else.
term: Contractor == An outside worker who may be granted internal access.
term: Visitor == A guest on the premises who should be supervised.
term: Biometric == A measurement of a body feature, used to authenticate.
term: Watering hole == Compromising a site that a target group is known to visit.
term: IoT == Internet of Things: connected everyday devices.
term: Cameras, sensors and printers == Common IoT devices that are often weakly protected.
term: OT == Operational technology: systems that control physical processes.
term: Lock and key == Physical access using traditional locks.
term: Access vestibule == A two-door space that controls entry one person at a time.
term: Access passes == Badges or cards that grant physical entry.
term: Bluetooth == Short-range wireless for connecting devices.
term: RF == Radio frequency: wireless signals that can be jammed or intercepted.
term: NFC == Near-field communications: very short-range wireless.
