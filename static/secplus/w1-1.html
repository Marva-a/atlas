What a computer actually is: hardware, CPU, memory and storage

Lesson 1 · Week 1 · Foundations · Foundation (not an exam objective) · Beginner · about 120 min

Open this lesson in Atlas →

Foundational technical knowledge

1. Learn the concept

By the end, you can

  • Name the main hardware parts of a computer and say what each one does.
  • Explain the difference between memory and storage, and why it matters when power is lost.
  • Describe the input, process, store, output cycle using an everyday task.

Why it exists and what problem it solves

Every security topic ends up on real hardware. Encryption keeps data safe on a disk, attackers hunt for passwords left in memory, and forensic investigators copy storage and memory in different ways because they behave differently. You cannot protect something you cannot picture.

In plain language

A computer is a machine that follows instructions on data. It takes something in (a key press, a file, a network message), works on it, keeps some of it, and gives something back (text on screen, a saved file, a reply).

Think of a kitchen. The cook is the CPU, doing the work one step at a time, very quickly. The counter is RAM: fast and within reach, but cleared at the end of the day. The pantry is storage: slower to reach, but its contents stay when the lights go out. The recipe is software.

2. Technical deep dive

The central processing unit (CPU) runs instructions. A modern CPU has several cores, and each core can work on its own stream of instructions. Random access memory (RAM) holds the programs and data in active use. RAM is volatile, which means its contents disappear when power is removed.

Storage is non-volatile: a solid-state drive (SSD) or hard disk drive (HDD) keeps data with the power off. A network interface card (NIC) connects the computer to a network. The motherboard links the parts together, and the power supply feeds them. Firmware, such as the BIOS or its modern replacement UEFI, is software stored on a chip that starts the machine before the operating system loads.

Everything inside the machine is stored as bits, each a 0 or a 1. Eight bits make one byte. One byte can represent 256 different values, from 0 to 255, a range you will meet again with IP addresses.

Key terms

HardwareThe physical parts of a computer.
SoftwareInstructions that tell hardware what to do.
CPUCentral processing unit: the part that executes instructions.
RAMRandom access memory: fast working space that is cleared when power is lost.
VolatileLost when the power goes off.
StorageLong-term, non-volatile space for files, such as an SSD.
NICNetwork interface card: the hardware that connects a device to a network.
FirmwareLow-level software stored on a chip, which runs before the operating system.
BIOS and UEFIFirmware that starts a computer. UEFI is the modern replacement for the older Basic Input/Output System.
Bit and byteA bit is a single 0 or 1. A byte is eight bits.

Walkthrough: Follow one keystroke

  1. You press the letter A. The keyboard sends a signal to the computer. That is input.
  2. The operating system receives it and hands it to the program in front of you.
  3. The CPU runs the program's instructions, and RAM holds the document you are typing.
  4. The program asks for the letter to be drawn, and the screen shows it. That is output.
  5. You press Save. The document is written from RAM to storage, where it now survives a power cut.

Hands-on lab

Find your own hardware

About 25 min. Your own computer

  1. Windows: open Settings, then System, then About. Then press Ctrl+Shift+Esc to open Task Manager and choose Performance.
  2. macOS: open the Apple menu, then About This Mac. Then open Activity Monitor from Applications, then Utilities.
  3. Write down your CPU model and core count, your total RAM, and your storage size and type.
  4. Open several browser tabs and watch memory use rise. Close them and watch it fall.

Expected: You have a short written inventory of your machine, and you saw RAM use change as programs opened and closed.

Memory use changes immediately because RAM holds what is active. Your storage figure stays nearly the same because closing a tab does not delete anything from the disk.

Done when:

  • You recorded CPU, RAM and storage values for your machine.
  • You can say in one sentence why RAM use changed but storage use did not.

3. See it in real products

Every product feature eventually becomes CPU work, memory use and stored data. That is why a design that loads a huge export in the browser can freeze a device, and why sensitive data held in memory or on disk has to be treated differently.

In security operations

  • Laptop theft: without disk encryption, a thief can remove the SSD and read the files directly. The password that protects the sign-in screen does not protect the disk itself.
  • Incident response: investigators capture memory before shutting a compromised machine down, because RAM may hold running malware and encryption keys that vanish with the power.

5. Test your understanding

A. Security+ technical assessment

Exam-style scenario: A company laptop is stolen from a car. It was powered off, and it has a sign-in password but no disk encryption. What can the thief do, and which part of the computer is the concern?

Compare your reasoning

The concern is storage. The sign-in password only controls access through the running operating system. A thief can remove the SSD or start the laptop from other media and read the files. RAM is not the concern here because it was cleared when the laptop lost power. Full disk encryption would address this risk.

1. Which component loses its contents when the power is turned off?

  • RAM
  • SSD
  • Hard disk drive
  • USB flash drive
Answer and explanation
  • Correct: RAM. RAM is volatile, so it needs power to keep its contents.
  • Incorrect: SSD. An SSD is non-volatile storage and keeps data with the power off.
  • Incorrect: Hard disk drive. A hard disk stores data magnetically and keeps it without power.
  • Incorrect: USB flash drive. A flash drive is non-volatile, which is why it can carry files between computers.

2. An investigator wants any encryption keys that are currently in use on a running server. Where are those keys most likely to be found, and what follows from that?

  • In RAM, so memory should be captured before the server is shut down
  • On the SSD, so the server should be shut down first
  • In the CPU's power supply, so it should be removed
  • In the NIC, so the network cable should be replaced
Answer and explanation
  • Correct: In RAM, so memory should be captured before the server is shut down. Keys in active use sit in memory, which is lost when power is removed.
  • Incorrect: On the SSD, so the server should be shut down first. Shutting down destroys the contents of RAM, which is exactly where keys in use are held.
  • Incorrect: In the CPU's power supply, so it should be removed. A power supply stores no data.
  • Incorrect: In the NIC, so the network cable should be replaced. A NIC moves network traffic and does not hold encryption keys in use by applications.

3. True or false: firmware runs before the operating system loads.

  • True
  • False
Answer and explanation
  • Correct: True. Firmware such as UEFI initializes the hardware and then starts the operating system.
  • Incorrect: False. The operating system cannot start until firmware has prepared the hardware.

4. Match each component to its job.

Correct matches
  • CPU: Executes instructions
  • RAM: Holds active programs and data
  • SSD: Keeps files long term
  • NIC: Connects the device to a network

Each part has one main job. Security questions often depend on knowing which part holds the data in question.

6. Review and references

Common mistakes

  • Thinking a sign-in password encrypts the disk. It only controls who can use the running system unless disk encryption is enabled.
  • Using memory and storage as if they mean the same thing. RAM is working space, while storage is long-term.

Summary

  • A computer takes input, processes it, stores some of it and produces output.
  • The CPU does the work, RAM is volatile working space and storage keeps data without power.
  • Where data sits decides how it can be stolen and how it must be protected.
