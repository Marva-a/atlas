The OSI and TCP/IP models, packets and encapsulation

Lesson 9 · Week 3 · Foundations · Foundation (not an exam objective) · Beginner · about 120 min

Open this lesson in Atlas →

Foundational technical knowledge

1. Learn the concept

By the end, you can

  • Name the seven OSI layers and map them to the TCP/IP model.
  • Explain encapsulation using segments, packets and frames.
  • Place common devices and protocols at the right layer.

Why it exists and what problem it solves

Security tools are described by layer. A Layer 4 firewall and a Layer 7 web application firewall see very different things. Exam questions and vendor documentation both assume you know the difference.

In plain language

Sending a letter involves layers. You write the letter, put it in an envelope, address it, the post office puts it in a sack, and a truck carries the sack. Each step only deals with its own wrapping. At the far end, each wrapping is removed in reverse order.

The OSI model is a teaching map with seven layers. TCP/IP is the practical model that the internet actually uses, with four layers. Both describe the same idea: each layer does one job and relies on the layer below.

2. Technical deep dive

From top to bottom, the OSI layers are 7 Application, 6 Presentation, 5 Session, 4 Transport, 3 Network, 2 Data Link and 1 Physical. The TCP/IP model groups them into Application, Transport, Internet and Link.

As data moves down the layers, each adds a header. This is encapsulation. At Layer 4 the unit is a segment (TCP) or datagram (UDP). At Layer 3 it is a packet. At Layer 2 it is a frame, and at Layer 1 it is bits on the medium. A router works mainly at Layer 3 using IP addresses. A switch works mainly at Layer 2 using MAC addresses.

Each router removes the frame and builds a new one for the next link. The IP packet inside keeps its source and destination, unless NAT changes them. That is why MAC addresses matter only locally.

OSI's seven layers beside the four TCP/IP layers that real networks use.

Each layer wraps the one above it. The receiver unwraps in reverse.

Key terms

OSI modelA seven-layer model that describes network communication.
TCP/IP modelThe four-layer model used by the internet.
EncapsulationWrapping data with a new header at each layer.
HeaderControl information added in front of data.
SegmentThe unit of data at the transport layer in TCP.
PacketThe unit of data at the network layer.
FrameThe unit of data at the data link layer.
Layer 4The transport layer, where TCP, UDP and port numbers operate.
Layer 7The application layer, where protocols such as HTTP operate.

Walkthrough: Follow an email down and up the layers

  1. Your mail application creates the message at the application layer.
  2. TCP adds a header with source and destination ports, forming a segment.
  3. IP adds source and destination addresses, forming a packet.
  4. The data link layer adds MAC addresses for the next hop, forming a frame, and sends it as signals.
  5. The receiver removes each wrapping in reverse until the mail server reads the message.

Hands-on lab

See the layers in a real capture

About 40 min. Wireshark (free), on your own traffic only

  1. Install Wireshark from wireshark.org. Capture on your own Wi-Fi or Ethernet interface for 30 seconds while you open a website, then stop.
  2. Click any TCP packet. In the middle pane, expand Frame, Ethernet, Internet Protocol and Transmission Control Protocol.
  3. Find a MAC address, an IP address and a port number, and match each to its layer.
  4. Do not capture on networks you do not own or lack permission to monitor.

Expected: The details pane shows the layers stacked, in the same order as encapsulation.

Wireshark displays each header separately because each layer added its own. Seeing this makes the abstract model concrete.

Done when:

  • You found a MAC address, IP address and port number in one packet.
  • You named the layer for each.

3. See it in real products

The layered model gives engineers a shared language: "that is a layer 7 problem" means the application rather than the network. Understanding that phrase is the practical gain for a designer.

In security operations

  • A Layer 4 firewall can allow traffic to port 443 but cannot see the web request inside it.
  • A Layer 7 device can tell the difference between a normal search and a request that contains an attack string.

5. Test your understanding

A. Security+ technical assessment

Exam-style scenario: A firewall allows all traffic to TCP port 443, yet an attack is arriving inside normal-looking web requests to that port. Why did the firewall not stop it, and what kind of device could?

Compare your reasoning

A firewall inspecting only Layer 3 and 4 information sees addresses and ports, not the content of the web request. A Layer 7 device, such as a web application firewall, can inspect the application data and block malicious requests.

1. At which OSI layer do routers mainly operate?

  • Layer 3, Network
  • Layer 2, Data Link
  • Layer 4, Transport
  • Layer 7, Application
Answer and explanation
  • Correct: Layer 3, Network. Routers forward packets using IP addresses.
  • Incorrect: Layer 2, Data Link. Switches mainly operate at Layer 2.
  • Incorrect: Layer 4, Transport. Layer 4 handles ports and end-to-end delivery.
  • Incorrect: Layer 7, Application. Layer 7 is where application protocols operate.

2. Order the OSI layers starting from the top.

Correct order
  1. Application
  2. Presentation
  3. Session
  4. Transport
  5. Network
  6. Data Link
  7. Physical

Layer 7 is at the top and Layer 1 at the bottom. One memory aid runs from the top: All People Seem To Need Data Processing.

3. Match the layer to its unit of data.

Correct matches
  • Transport: Segment
  • Network: Packet
  • Data Link: Frame
  • Physical: Bits

Each layer's name for its unit comes from how it wraps the data.

4. Which information can a device examining only Layer 3 see?

  • Source and destination IP addresses
  • The URL requested by a browser
  • The contents of an encrypted web page
  • The username typed into a form
Answer and explanation
  • Correct: Source and destination IP addresses. Layer 3 is the IP layer.
  • Incorrect: The URL requested by a browser. A URL is application-layer data.
  • Incorrect: The contents of an encrypted web page. That is application data, and encrypted as well.
  • Incorrect: The username typed into a form. A form field is application-layer data.

6. Review and references

Common mistakes

  • Believing the OSI model describes exactly how the internet is built. It is a reference model, while TCP/IP is what is implemented.
  • Thinking a switch reads IP addresses in all cases. Standard switching uses MAC addresses, while multilayer switches can also route.

Summary

  • OSI has seven layers, and TCP/IP groups them into four.
  • Each layer wraps the one above it, and the receiver unwraps in reverse.
  • A device's layer decides what it can see and control.

References
