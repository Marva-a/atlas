What a network is: LAN, WAN, topology and devices

Lesson 5 · Week 2 · Foundations · Foundation (not an exam objective) · Beginner · about 120 min

Open this lesson in Atlas →

Foundational technical knowledge

1. Learn the concept

By the end, you can

  • Define LAN, WAN, internet and intranet.
  • Describe the job of a hub, switch, router, access point and gateway.
  • Recognize star, mesh, bus and ring topologies.

Why it exists and what problem it solves

Almost every attack travels over a network, and almost every defense is placed somewhere on one. To decide where a firewall belongs, or how far an infection could spread, you first need to know how the pieces connect.

In plain language

A network is two or more devices connected so they can exchange data. A LAN is like the internal mail system of one building: fast and local. A WAN connects distant buildings, like the postal service between cities. The internet is the worldwide network of networks.

Different devices have different jobs. A switch is the mail room inside one building, delivering each letter only to the right desk. A router is the post office that sends mail on to other cities. A hub is an old mail room that photocopies every letter and hands it to everyone.

2. Technical deep dive

A local area network (LAN) covers a limited area such as an office. A wide area network (WAN) spans large distances. The internet is the public global network that uses the Internet Protocol. An intranet is a private network service available only inside an organization.

A hub repeats incoming signals out of every port. A switch learns which device is on each port and forwards traffic only where it needs to go. A router moves traffic between different networks. A wireless access point (AP) connects Wi-Fi devices to a wired network. A gateway is the device that traffic passes through to leave the local network; on most home and office networks, the router is the default gateway.

Topology describes how a network is arranged. In a star, devices connect to a central switch. In a mesh, devices have multiple links to each other, giving redundancy. In the older bus and ring designs, devices shared a single line or passed data around a loop.

Walkthrough: Trace a message across the network

  1. A laptop wants to print to a printer in the same office. The switch sends the data straight to the printer's port.
  2. The same laptop now opens a website. The destination is not local, so the laptop sends the data to its default gateway.
  3. The router forwards it out toward the internet, from router to router.
  4. The reply follows the reverse journey and reaches the laptop through the switch or access point.

Hands-on lab

Map your own network

About 30 min. Paper or any drawing tool, and your router's label

  1. List every device connected to your home or office network that you are allowed to look at: phones, laptops, printers, televisions.
  2. Draw your network. Mark your internet connection, your router and each device. Note which devices use Wi-Fi and which use a cable.
  3. Label where the switch, access point and router functions are. Remember they may all be in one box.

Expected: A simple diagram showing devices, the gateway and the connection to the internet.

A network diagram is a core security artifact. Each extra device you found is part of what must be protected.

Done when:

  • Your diagram shows the gateway, at least two devices and the internet connection.
  • You can state which device function moves data to other networks.

3. See it in real products

Networks explain why a product behaves differently on office Wi-Fi, a VPN or a phone connection, and why corporate customers sometimes report that a feature is "blocked".

In security operations

  • A home has one box that combines a router, a switch, an access point and a firewall, which is why these separate jobs are easy to confuse.
  • Bank branches connect to the head office over a WAN. If a branch is compromised, that WAN link is a path that attackers may try to follow.

5. Test your understanding

A. Security+ technical assessment

Exam-style scenario: An office still uses a hub to connect its computers. One computer is infected with software that records network traffic. Why is this worse than if the office used a switch?

Compare your reasoning

A hub repeats all traffic to all ports, so the infected computer can see everyone's traffic. A switch sends traffic only to the intended port, so ordinary sniffing would see far less. Switching is not a complete defense, but a hub gives an attacker this visibility for free.

1. Which device moves traffic between different networks?

  • Router
  • Switch
  • Hub
  • Access point
Answer and explanation
  • Correct: Router. Routers connect networks and decide where traffic goes next.
  • Incorrect: Switch. A switch forwards traffic within one local network.
  • Incorrect: Hub. A hub simply repeats signals to every port.
  • Incorrect: Access point. An access point connects wireless devices to a network.

2. A device sends traffic to an address outside its local network. Where does it send that traffic first?

  • Its default gateway
  • Every device on the LAN
  • The DNS server
  • The nearest printer
Answer and explanation
  • Correct: Its default gateway. The default gateway is the exit from the local network.
  • Incorrect: Every device on the LAN. Traffic for another network does not go to each local device.
  • Incorrect: The DNS server. DNS translates names, but does not forward application traffic.
  • Incorrect: The nearest printer. A printer is simply another local device.

3. Match each term to its description.

Correct matches
  • LAN: One office or building
  • WAN: Multiple distant locations
  • Internet: The global public network
  • Intranet: An internal service for one organization

These terms describe the reach and the audience of a network.

4. True or false: a switch sends traffic only to the correct port when it knows the destination.

  • True
  • False
Answer and explanation
  • Correct: True. A switch learns which devices are on which ports so it can forward selectively.
  • Incorrect: False. Sending traffic out of every port describes a hub.

6. Review and references

Common mistakes

  • Calling the box at home a router and assuming that is all it does. It usually combines several functions.
  • Treating an intranet as safe because it is internal. Internal networks are a common path for attackers after an initial compromise.

Summary

  • A LAN is local, a WAN spans distances, and the internet connects networks globally.
  • Switches work within a network, routers work between networks.
  • Network layout decides what an attacker can see and reach.
