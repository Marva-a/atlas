Subnet masks and basic subnetting

Lesson 7 · Week 2 · Foundations · Foundation (not an exam objective) · Beginner · about 120 min

Open this lesson in Atlas →

Foundational technical knowledge

1. Learn the concept

By the end, you can

  • Explain what a subnet mask and CIDR notation mean.
  • Work out the network address, broadcast address and usable hosts for simple subnets.
  • Decide whether two addresses are on the same subnet.

Why it exists and what problem it solves

Subnets are the basic building block of network segmentation, and segmentation limits how far an attacker can move. Firewall rules and logs are written with subnet notation, so you need to be able to read a range like 10.20.30.0/24 at a glance.

In plain language

A subnet is a neighbourhood within a town. Part of an address says which neighbourhood, and the rest says which house. The subnet mask tells you where the neighbourhood part ends.

If two devices are in the same neighbourhood, they can talk directly. If they are in different neighbourhoods, they must go through a router, and that router is a place where the conversation can be checked or blocked.

2. Technical deep dive

A subnet mask marks which bits of an IP address are the network part. The mask 255.255.255.0 means the first 24 bits are the network and the last 8 bits identify the host. Classless Inter-Domain Routing (CIDR) notation writes the same thing as /24, which is the count of network bits.

Host bits equal 32 minus the prefix. The total number of addresses is 2 raised to the host bits. In a normal IPv4 subnet, two addresses are reserved: the first is the network address and the last is the broadcast address. Usable hosts therefore equal 2 raised to the host bits, minus 2.

To find a subnet with a mask that ends on an octet boundary, keep the network octets and set the rest. For 192.168.5.77/24, the network is 192.168.5.0, the broadcast is 192.168.5.255 and hosts run from .1 to .254. For prefixes in the middle of an octet, find the block size by subtracting the mask's last value from 256. For /26, the mask ends in 192, so the block size is 64 and networks start at 0, 64, 128 and 192.

The prefix says where the network part ends. What is left over numbers the devices.

Key terms

SubnetA smaller network carved from a larger address range.
Subnet maskA value that shows which bits of an address identify the network.
CIDRClassless Inter-Domain Routing: writing a network with a prefix length, such as /24.
Prefix lengthThe number of network bits, shown after the slash.
Network addressThe first address in a subnet, which identifies the subnet itself.
Broadcast addressThe last address in a subnet, used to reach all hosts in it.
HostAny device with an address on a network.

Walkthrough: Are 192.168.1.70 and 192.168.1.130 on the same /26?

  1. A /26 has a block size of 64, so subnets in the last octet start at 0, 64, 128 and 192.
  2. The address 192.168.1.70 falls in the block 64 to 127.
  3. The address 192.168.1.130 falls in the block 128 to 191.
  4. They are in different subnets, so traffic between them must go through a router.
  5. Under a /24 mask, they would have been on the same subnet.

Hands-on lab

Subnet by hand

About 40 min. Pencil and paper; check using any free subnet calculator

  1. For 10.0.8.45/24, write the network, broadcast and usable host range.
  2. For 172.16.4.200/26, find the block size, network, broadcast and usable hosts.
  3. Decide whether 192.168.2.14/28 and 192.168.2.20/28 are on the same subnet.
  4. Design subnets for a small office: 50 staff devices, 20 guest devices and 10 servers, from 192.168.10.0/24.

Expected: 10.0.8.0, 10.0.8.255 and hosts .1 to .254. Then 172.16.4.192, 172.16.4.255 and hosts .193 to .254. The /28 pair are in different subnets (blocks 0 to 15 and 16 to 31). One valid office design is /26 for staff, /27 for guests and /28 for servers, without overlaps.

The block size tells you where each subnet starts. Separate subnets for staff, guests and servers create boundaries where traffic can be controlled.

Done when:

  • Your first three answers match the expected ones.
  • Your office design gives each group enough usable addresses and no ranges overlap.

3. See it in real products

Subnetting rarely reaches an interface directly. It matters because enterprise administrators may enter address ranges such as 203.0.113.0/24 into allow lists, and that field needs validation and a clear preview of what it covers.

In security operations

  • A company gives accounting 10.1.10.0/24 and guests 10.1.50.0/24. A router between them can block guests from reaching accounting.
  • A firewall rule that allows 203.0.113.0/28 is allowing exactly 16 addresses, so a single typo in the prefix can open access to far more.

5. Test your understanding

A. Security+ technical assessment

Exam-style scenario: Guests and staff share the subnet 10.5.0.0/24. A guest's infected phone begins probing staff laptops directly. What change reduces this risk at the network level?

Compare your reasoning

Place guests in their own subnet, ideally on a separate VLAN, and route between the subnets through a firewall that blocks guest-to-staff traffic. On the same subnet, devices talk directly and no router has a chance to filter the traffic.

1. How many usable hosts are in a /24 IPv4 subnet?

  • 254
  • 256
  • 255
  • 24
Answer and explanation
  • Correct: 254. A /24 has 256 addresses, minus the network and broadcast addresses.
  • Incorrect: 256. That is the total number, including the two reserved addresses.
  • Incorrect: 255. Two addresses are reserved, not one.
  • Incorrect: 24. The 24 is the number of network bits, not hosts.

2. What is the network address of 192.168.1.130/26?

  • 192.168.1.128
  • 192.168.1.0
  • 192.168.1.64
  • 192.168.1.192
Answer and explanation
  • Correct: 192.168.1.128. A /26 has blocks of 64 and 130 falls in the block that starts at 128.
  • Incorrect: 192.168.1.0. That would be the network if the prefix were /24.
  • Incorrect: 192.168.1.64. That block ends at 127, so 130 is outside it.
  • Incorrect: 192.168.1.192. That block starts after 130.

3. A team needs 28 usable addresses and wants the smallest subnet that fits. Which prefix should it use?

  • /27
  • /28
  • /26
  • /30
Answer and explanation
  • Correct: /27. A /27 gives 30 usable hosts, which is the smallest size that holds 28.
  • Incorrect: /28. A /28 gives only 14 usable hosts.
  • Incorrect: /26. A /26 fits but is larger than necessary.
  • Incorrect: /30. A /30 gives only 2 usable hosts.

4. True or false: two devices on different subnets need a router to communicate.

  • True
  • False
Answer and explanation
  • Correct: True. Traffic between subnets is forwarded by a router or a layer 3 device.
  • Incorrect: False. Direct delivery only works within a subnet.

6. Review and references

Common mistakes

  • Forgetting to subtract the network and broadcast addresses when counting usable hosts.
  • Copying a firewall rule with the wrong prefix. A /16 in place of a /24 allows 256 times as many addresses.

Summary

  • A mask or CIDR prefix separates the network part from the host part of an address.
  • Usable IPv4 hosts equal 2 raised to the host bits, minus 2.
  • Subnets create boundaries where traffic can be controlled.

References

  • RFC 4632: Classless Inter-domain Routing (CIDR) (IETF, required)
  • RFC 1918: Address Allocation for Private Internets (IETF, supplementary)
